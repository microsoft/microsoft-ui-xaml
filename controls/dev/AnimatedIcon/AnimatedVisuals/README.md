# AnimatedVisuals

The `Animated*VisualSource` classes in this folder are C++/WinRT code generated by
[LottieGen](https://github.com/CommunityToolkit/Lottie-Windows) from Lottie (`.json`) animations.

Only `AnimatedGlobalNavigationButtonVisualSource.json` (the NavigationView hamburger) is checked in. Its 2021 source was
not, so it was rebuilt from the generated code in 2026 (#7048). Regenerating the original 2021 values from it gives the
checked-in 2021 `.cpp`/`.h` byte for byte, apart from the input file size and date in the header.

## Hamburger pixel grid

The animation is 48x48 and is drawn at 16x16, so 3 units are 1 pixel at 100% scale. To stay crisp, each bar is
3 units thick (layer scale 300% of a 1 unit high path) and centred on canvas y 7.5, 22.5 and 37.5, i.e. on pixel
rows 2, 7 and 12, the rows of the `E700` (GlobalNavigationButton) glyph in Segoe Fluent Icons. Keep this in mind for
every frame where the icon rests: the end of each `*_End` marker.

## Regenerating

1. Edit the `.json`.
2. Run LottieGen 7.1.0 (the `LottieGen` .NET tool package) in this folder:

   ```
   LottieGen -Language Cppwinrt -WinUIVersion 2.4 -InputFile AnimatedGlobalNavigationButtonVisualSource.json
   ```

3. Port the output (`AnimatedVisuals.<Name>.cpp/.h`) to the layout of the checked-in files and replace them:
   - `Windows::UI::Composition` / `Windows.UI.Composition.h` become `Microsoft::UI::Composition` /
     `Microsoft.UI.Composition.h`.
   - Header: include `common.h` and `AnimatedVisuals\<Name>.g.h`; remove the `winrt::AnimatedVisuals` and
     `implementation` namespaces and the `factory_implementation` struct; the class derives from
     `winrt::implementation::<Name>T<<Name>>`.
   - Source: include `AnimatedVisuals\<Name>.h`, drop the `__has_include` block and the `BUILD_WINDOWS` block around
     `Windows.Graphics.Effects.Interop.h`; replace `namespace winrt::AnimatedVisuals::implementation` with
     `CppWinRTActivatableClassWithBasicFactory(<Name>)` inside `namespace winrt::Microsoft::UI::Xaml::Controls::AnimatedVisuals`
     followed by `#include "AnimatedVisuals\<Name>.g.cpp"`, un-indent the rest, and qualify `float2`, `float3x2` and
     `float4` as `winrt::float2` etc.
   - Keep the `.idl` and `controls\dev\Generated\<Name>.properties.cpp` unchanged.
4. Check the markers and theme properties didn't change (`AnimatedIconTests.*VisualSourceContract`) and that the
   hamburger is still on whole pixels (`AnimatedIconTests.AnimatedGlobalNavigationButtonBarsAreOnWholePixelsAtRest`).
