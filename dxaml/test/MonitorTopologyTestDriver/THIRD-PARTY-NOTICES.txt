===========================

.NET TFM. The .NET SDK resolves the official Microsoft.Windows.SDK.NET.Ref
targeting pack (10.0.19041.57 in this build), including Windows SDK projections
and the C#/WinRT runtime. Its package metadata points to Microsoft's Windows
SDK license, not the root MIT license:
