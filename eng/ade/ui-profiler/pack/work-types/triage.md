# Triage

1. Describe the signal: the issue, the error, the telemetry or the user report.
2. Estimate the impact: who is affected, how often and how badly.
3. Read the code and the team knowledge. Give one or more root cause hypotheses with file paths.
4. List the next actions with an owner type: fix now, add telemetry, investigate or close.
5. Write only the deliverable. Do not change source files.
